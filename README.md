This is a fork of [https://github.com/Muttley/foundryvtt-ac2d20](https://github.com/Muttley/foundryvtt-ac2d20) with the aim of making the system usable for the similar [Cohors Cthulhu][1] game in the [Foundry VTT][2] virtual tabletop . Most of the underlying code remains the same, with just some minor alterations for the different mechanics, and the styling, icons and imagery, etc.

This is a pretty dirty hack-job to get a usable system for our gaming group. Hopefully that will improve in time.

---

## System Overview

The system provides:

- Actor sheets for Character, NPC and Vehicle Actors.
- Item sheets for Weapons, Armor, Talents, Spells, Skill Kits, Special Rules and Equipment.
- Skills Compendium. List of Skills with their Focuses. Dragg the Skills you need from the compendium to the NPC sheets.
- Macros Compendium. 2 Macros for rolling D20 and Stress(d6) dice. You can drag those to you macro bar.
- The system supports Dice-So-Nice module and introduces its own stress dice shortcut ("s") that you can use in chat or in journals (example: "`/r 1ds`", "`[[/r 1ds]]`", "`[[1ds]]`")

**IMPORTANT:** The system doesn't provide any pre-populated content.
